# 🏥 Healthcare Operations Intelligence

## Patient Flow, Wait Time & Service Efficiency Analytics

Healthcare organizations face increasing patient demand while striving to maintain efficient operations and positive patient experiences.

This project analyzes 9,000+ patient encounters collected between April 2023 and October 2024 to identify operational bottlenecks, patient flow inefficiencies, staffing challenges, and factors impacting patient satisfaction.

Using SQL and healthcare analytics techniques, the analysis delivers actionable recommendations to improve healthcare operations and support data-driven decision-making.
